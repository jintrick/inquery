# Issue: 複数行入力モードへの遷移トリガーを「空入力」に変更

## 背景と問題点
現在、複数行入力モード（Zenity `--text-info`）へ遷移するには、入力欄に `..` と入力して Enter を押す必要がある。これはマジック文字列（`..`）に依存しており、直感的ではない。また、通常の検索クエリと競合する可能性（極めて低いが）もある。

## 解決策
1行入力（Zenity `--entry`）において、**未入力（空文字）の状態で Enter を押した場合**に複数行入力モードへ遷移するように変更する。これにより、`..` という特別な入力を覚える必要がなくなる。

## 実装内容詳細
1.  **`bin/inquery` の修正**
    - `if [ "$QUERY" = ".." ]; then` の条件を `if [ -z "$QUERY" ]; then` に変更する。
    - Zenity のタイトルバー等のメッセージを、`..` への言及から「空のまま Enter で複数行モード」といった内容に更新する。
    - 関連するコメントも最新の挙動に合わせて修正する。
2.  **`GEMINI.md` の更新**
    - 「各モジュールの責務」における `bin/inquery` の記述を、新しい仕様に合わせて更新する。
