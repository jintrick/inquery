# Issue: インストールプロセスの簡素化（一発インストールの実現）

## 背景と問題点
現在、`inquery` を利用するためには手動でのシンボリックリンク作成や設定が必要であり、利用者から「単に面倒」というフィードバックを受けている。また、`README.md` も手動手順が中心となっており、導入の障壁が高い。

## 解決策
- **最小構成のインストーラー (`install.sh`)**: 複雑な判定や環境への干渉を排除し、配置（シンボリックリンク作成とデスクトップ統合）のみを「強制上書き」で実行する堅牢なスクリプトを完成させる。
- **README.md の再構成**: 冒頭に「一発インストール」のみを記載し、手動手順は末尾に移動することで、ユーザーが迷う余地を最小化する。

## 実装内容詳細

### 1. `install.sh` のブラッシュアップ（MVP）
- `ln -sf` による強制シンボリックリンク作成（`~/.local/bin/inquery`）。
- `sed` を使用したデスクトップファイルの生成と配置（`~/.local/share/applications/inquery.desktop`）。
- **追加**: `bin/inquery` への実行権限付与 (`chmod +x`) の確実な実行。
- 複雑な環境チェック（PATHの有無、依存ソフトの確認など）は行わず、完了時のメッセージで補足するに留める。

### 2. `README.md` の刷新
- **冒頭 (Quick Start)**: `git clone` と `./install.sh` の実行手順のみを記載。
- **設定**: カスタマイズ用の設定ファイルの配置場所を 1 行で説明。
- **末尾 (Advanced Installation)**: 既存の手動手順をセクションとして移動し、必要なユーザーのみが参照できるようにする。

## 規約準拠 (Rule Compliance)
- **comment-preservation.md**: 既存のコメントを維持し、追加ロジックは最小限に留める。
