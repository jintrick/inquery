# Issue: Schema Extension (`show_if_contains` / `copy_to_clipboard`)

## 目的
アクションの表示条件および実行前処理を柔軟にするため、`actions.json` のスキーマを拡張する。

## 修正対象
- `config/actions.json.example`
- `lib/filter.py`
- `lib/executor.py`
- `tests/test_filter.py`
- `tests/test_executor.py`

## 実装内容詳細 (Atomic Steps)
以下の手順を **Atomic** かつ **Deterministic** に実行せよ。

1. **`config/actions.json.example` の修正**
   - Gemini, Claude, Grok の設定例を追加する。
   - 各設定例に `show_if_contains: ["。", "、", ",", "？"]` および `copy_to_clipboard: true` プロパティを含める。

2. **`lib/filter.py` の修正**
   - jsonからパースしたデータに `show_if_contains` (`Optional[List[str]]`) が含まれている場合の処理を追加する。
   - **表示条件ロジック**:
     - クエリが空文字の場合: `show_if_contains` の設定を無視し、無条件で表示候補に含める。
     - クエリが空ではない場合:
       - ユーザーがアクションの `label` 名を完全一致（または部分一致）で入力した場合: 常に表示候補に含める。
       - それ以外の場合で、`show_if_contains` に指定された文字列のいずれかがクエリに含まれている場合: 表示候補に含める。
       - 上記いずれも満たさない場合: 表示候補から除外する。

3. **`lib/executor.py` の修正**
   - アクションデータから `copy_to_clipboard` (`Optional[bool]`) をパースする処理を追加する。
   - `True` の場合、アクション実行（`subprocess.Popen` などによる起動）の直前に、クエリ文字列をクリップボードにコピーする処理を挿入する。
   - **コピー処理のフォールバックロジック**:
     - `subprocess.run` を用い、`echo -n "$query" | xclip -selection clipboard` を実行する（shell=Trueを推奨、またはPopenとpipeを組み合わせる）。
     - `xclip` の実行が失敗した（終了コード非0）、またはコマンドが存在しない(`FileNotFoundError`)場合、フォールバックとして `echo -n "$query" | xsel --clipboard --input` を実行する。
     - いずれも失敗した場合はエラーを出力して処理を続行する（アクション自体の実行は止めない）。

## テスト項目詳細 (Test Specifications)

1. **`tests/test_filter.py` の追加・修正**
   - 以下の条件で `filter_actions` 関数の振る舞いを検証する。
   - **Test Case 1: クエリが空文字の場合**
     - 入力: query="", `show_if_contains` を持つアクション
     - 期待値: アクションが表示候補としてリストに返されること。
   - **Test Case 2: `show_if_contains` の条件を満たす場合**
     - 入力: query="今日の天気は？", `show_if_contains=["。", "？"]` を持つアクション
     - 期待値: アクションが表示候補として返されること。
   - **Test Case 3: `show_if_contains` の条件を満たさない場合**
     - 入力: query="今日の天気", `show_if_contains=["。", "？"]` を持つアクション
     - 期待値: アクションが表示候補から除外されること。
   - **Test Case 4: 条件を満たさないが、ラベル名と一致する場合**
     - 入力: query="gemini", `show_if_contains=["？"]`, label="Geminiで検索"
     - 期待値: アクションが表示候補として返されること（大文字小文字を区別せず部分一致・完全一致の検証）。

2. **`tests/test_executor.py` の追加・修正**
   - `copy_to_clipboard` が有効な際に関数が期待通りに外部コマンドを呼び出しているかを `unittest.mock.patch` を用いて検証する。
   - **Test Case 1: `xclip` によるコピーが成功するパターンの検証**
     - 前提: `subprocess.run` をモックし、`xclip` コマンド呼び出し時に成功（`returncode=0`）を返すように設定。
     - 検証: 指定されたクエリを含む `xclip` コマンドが引数として正しく `subprocess.run` に渡され、呼び出されたこと。`xsel` が呼び出されていないこと。
   - **Test Case 2: `xclip` が失敗し `xsel` にフォールバックするパターンの検証**
     - 前提: `subprocess.run` をモックし、1回目の呼び出し（`xclip`）で例外（`FileNotFoundError`）または失敗（`returncode!=0`）を発生させ、2回目の呼び出し（`xsel`）で成功を返すよう設定。
     - 検証: `xclip` 呼び出し後に `xsel` の呼び出しが行われていること。
   - **Test Case 3: `copy_to_clipboard` が `False` または未指定の場合**
     - 前提: アクションデータに同プロパティがない。
     - 検証: `subprocess.run` によるクリップボード関連のコマンドが一切呼び出されないこと。
